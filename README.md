# 🧩 Word Blocks

**A simple, levelled word generator for parents and children practising phonics and early reading.**

Word Blocks is a lightweight reading tool designed to take the guesswork out of choosing practice words. Pick a word length, word type and difficulty, then generate words for a child to sound out with a parent, caregiver or teacher alongside them.

**Free. Open source. No ads. No accounts. No tracking.**

## 🚀 Use Word Blocks

Live app:

https://jamesparkerbrown.github.io/word-blocks/

Word Blocks is a Progressive Web App (PWA), so it can be used directly in a browser or installed onto a phone or tablet. After it has loaded successfully, it can also work offline.

## 👨‍👩‍👧 Designed to learn together

Word Blocks is designed to be shared with a child, not to monitor them.

There is deliberately no:

- microphone access
- voice recording
- speech recognition
- pronunciation tracking
- AI analysis of a child's voice
- automated voice praise
- child profiles
- accounts
- behavioural tracking

**Word Blocks provides the words. The adult provides the teaching.**

## 🧠 How it works

Choose:

- 3, 4 or 5 letters
- Real words or Sound-it-out words
- Easy, Medium or Hard
- UK/Australian or US English

Then tap **New word**.

Difficulty is cumulative:

- **Easy** uses Easy words.
- **Medium** includes Easy and Medium words, weighted toward Medium.
- **Hard** includes Easy, Medium and Hard words, weighted toward Hard.

The app also avoids repeating words from the previous 25 displayed words where possible.

## 🌍 Open source

Word Blocks is open source so parents, teachers and developers can inspect it, improve it and adapt it.

Useful contributions include:

- phonics classification corrections
- improved word lists
- accessibility improvements
- regional English improvements
- UI improvements

## 📱 Install

### Android

Open the live app in Chrome and use **Install** when offered.

### iPhone / iPad

Open the live app in Safari, tap **Share**, then **Add to Home Screen**.
